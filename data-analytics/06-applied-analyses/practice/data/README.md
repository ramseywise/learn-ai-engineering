# South German Credit

`SouthGermanCredit.asc` and `codetable.txt` are the data and code table from the UCI Machine Learning Repository: [South German Credit (UPDATE)](https://archive.ics.uci.edu/dataset/573/south+german+credit+update), licence CC BY 4.0. Contributed by Ulrike Grömping; background in her report [South German Credit Data: Correcting a Widely Used Data Set](http://www1.beuth-hochschule.de/FB_II/reports/Report-2019-004.pdf) (Beuth Hochschule, Reports in Mathematics, Physics and Chemistry 04/2019). The files are unmodified.

1000 credits from 1973 to 1975 at a large regional bank in southern Germany, stratified to 700 good and 300 bad. In the file `kredit` = 1 is good and 0 is bad. Bad credits were heavily oversampled: the sources report an actual bad rate of about 5%.
