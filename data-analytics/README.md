# Data Analytics

Statistics and analysis on top of the Python data stack. The Python itself (language, pandas,
plotting) is taught in [`programming/python/`](../programming/python/README.md).

**Learning path:** For the recommended sequence (Python fundamentals → data wrangling → EDA/visualization → feature engineering → statistical analysis → modeling/BI), start with [CURRICULUM.md](CURRICULUM.md).

## Contents

- **`5_Statistical_Analysis.ipynb`**: distributions, hypothesis tests, A/B testing, correlation vs causation.
- **`courses/`**: own scripts from the Michigan and Wesleyan statistics courses (data not included).
- **`Bayes/`**: Bayesian inference and Bayesian A/B testing.
- **Moved 2026-10-29:** `python-basics/` (the seven `1_Overview` → `7_Time_Series` notebooks) is now
  [`programming/python/04-python-for-data/`](../programming/python/04-python-for-data/README.md).
- **In data-science:** [`Text Analytics with Python/`](../data-science/Text%20Analytics%20with%20Python/), companion code for Dipanjan Sarkar's *Text Analytics with
  Python* (chapters 01–10: NLP basics, text processing, feature engineering, classification,
  summarization/topic modeling, similarity/clustering, semantic and sentiment analysis). Reference/course
  material, not original work.

Also present: `readings/Python for Data Analysis.pdf` (O'Reilly reference) and `SimpleHacks.md` (quick-reference
notes).
