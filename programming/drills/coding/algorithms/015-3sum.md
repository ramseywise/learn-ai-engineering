## Prompt

Given an integer array `nums`, return all unique triplets `[nums[i], nums[j],
nums[k]]` (distinct indices) that sum to `0`. The result must not contain duplicate
triplets. Example: `nums = [-1,0,1,2,-1,-4]` -> `[[-1,-1,2],[-1,0,1]]`.

<details><summary>Hint 1</summary>

Sort the array first, then fix one element and look for the remaining pair. Use two pointers moving toward each other from the ends of the rest.

</details>

<details><summary>Hint 2</summary>

With the array sorted, move the left pointer right when the two-pointer sum is too small, and move the right pointer left when it's too big. Skip past duplicate values on both the fixed element and the pointers to avoid repeated triplets.

</details>

<details><summary>Hint 3</summary>

Sorting once plus this two-pointer sweep for each fixed element gives O(n^2) time overall.

</details>

## Solution

<details><summary>Reference approach</summary>

Sort the array, then fix each element a in turn and reduce to a two-sum on the remaining suffix using two pointers. Fast-forward a past any value equal to the previous one to avoid duplicate triplets. With target = -a, put b at the element after a and c at the rightmost element. If a + b == target, record (a, b, c) and move both pointers inward, skipping over repeated values on each side. If the sum is too small move b right, if too big move c left. (An alternative is to count every element in a hash and reason about how many times each distinct value appears, using a set to dedupe.)

```python
sort(nums)
for i in 0..n-3:
    if i > 0 and nums[i] == nums[i-1]: continue   # skip dup a
    target = -nums[i]
    j = i+1; k = n-1
    while j < k:
        s = nums[j] + nums[k]
        if s == target:
            output (nums[i], nums[j], nums[k])
            while j < k and nums[j] == nums[j+1]: j++
            while j < k and nums[k] == nums[k-1]: k--
            j++; k--
        elif s < target: j++
        else:            k--
```

**Complexity** — time O(n^2); space O(1) beyond the output (excluding sort)
