as a `web/` topic.

## Gaps

This is a scaffold, not a track yet. TypeScript's teaching lives in
[`programming/typescript/`](../../../programming/typescript/README.md).

| Area | Gap |
|---|---|
| Fixed problem sets | Use the HackerRank TypeScript or JavaScript tracks; solutions stay local |
| Language idioms | Types and generics, narrowing, `async`/`await`, modules |
| Web (HTML/CSS) | Semantic markup, flexbox/grid layout, DOM events, fetch + render |

**Order to build**: `types/` and `async/` schema drills, then `web/`.
