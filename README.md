# learn-ai-engineering

A self-paced curriculum for AI and data engineering: notes, notebooks, exercises and course material, organized into six subjects.

**Where to start:** [CURRICULUM.md](CURRICULUM.md) has the program outcomes and five learning paths: data analyst, data scientist, data engineer, AI engineer, and full-stack data and AI. Each subject README is the syllabus for that subject.

## Subjects

| Subject | What it covers |
|---|---|
| [Programming](programming/README.md) | [Python](programming/python/README.md), [SQL](programming/sql/README.md) and [TypeScript](programming/typescript/README.md), from first principles to production idioms, plus [computer science foundations](programming/computer-science/README.md) and [software design](programming/software-design/README.md) |
| [Data Analytics](data-analytics/README.md) | pandas, statistics, experimentation and causality, Bayesian analysis, visualisation, and applied analyses |
| [Data Engineering](data-engineering/README.md) | Built around *Designing Data-Intensive Applications*: storage, ingest and modelling, orchestration, lakehouse and streaming, quality, ML platform, governance |
| [Data Science](data-science/README.md) | Classical ML, deep learning, NLP, time series and recommenders |
| [Generative AI](generative-ai/README.md) | LLM fundamentals, RAG, agents, frameworks, RL and alignment, observability, evaluation, applications, LLMs from scratch |
| [AI Engineering](ai-engineering/README.md) | Prompt, context, harness, loop and graph, plus inference, multimodal, and safety and security. Labs in TypeScript and Python |

Generative AI builds things with LLMs; AI Engineering is the discipline that makes them reliable.
