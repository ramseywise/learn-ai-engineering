# Examples — Case Study Round

Worked cases covering the round's formats. Every example walks through the full template with realistic content, trade-off narration, and a measurement close.

**The split is by domain, not by format.** `ml-track/` holds classical ML/DS cases; `aie-track/` holds LLM and AI-engineering cases. Each track spans multiple formats — a live case and a take-home can sit side by side in the same track.

## How to use these

- **Before practice:** read the example once to internalize the template rhythm.
- **During drills:** close the file, pick a prompt, run the template out loud. Then compare.
- **Defense prep:** give the design to a peer and ask them to reproduce the challenge questions in [rag-pipeline-defense.md](aie-track/rag-pipeline-defense.md).
